HIS Connect API

API สำหรับเชื่อมต่อ HIS กับระบบต่าง ๆ เช่น nRefer, PHER Plus, MOPH ERP และ MOPH Kiosk

เวอร์ชันปัจจุบัน: 3.11.2-2026.10.24-2

ติดตั้งด้วย Docker (แนะนำ)

1. ติดตั้ง Docker (กรณีที่ยังไม่ติดตั้ง)

2. สร้าง folder และ file ที่จำเป็น (เช่น folder his_connect)

2.1 สร้าง folder เพื่อติดตั้ง API ด้วยคำสั่ง mkdir his_connect
2.2 cd his_connect
2.3 download file (docker-compose.yml, config, sent_result.txt) จาก https://github.com/superpck/his-connect/tree/main/his_connect_docker ทั้ง 3 files
2.4 แก้ไขค่าใน file config ให้ถูกต้อง
2.5 หากต้องการเปลี่ยน port ให้เปลี่ยนใน file docker-compose.yml
    บรรทัด "3004:3004" เป็น port ตามต้องการ เช่น "8080:3004"

โครงสร้าง folder หลังสร้างเสร็จแล้ว
 - his_connect
   |- docker-compose.yml
   |- config
   |- sent_result.txt

file ที่จำเป็นสำหรับ 2.3 (docker-compose.yml, config, sent_result.txt): github

3. สั่งให้ his-connect api (docker) ทำงาน (ภายใต้ folder ที่มี file config ตามข้อ 2)

docker compose up -d
# หรือ
docker-compose up -d

4. ตรวจสอบการทำงานของ his-connect api

docker compose logs -f
# หรือ
docker-compose logs -f

5. สั่งให้ his-connect api (docker) หยุดทำงาน (ถ้าต้องการ)

docker compose down
# หรือ
docker-compose down

6. ลบ image file ออกจากเครื่อง (ถ้าต้องการ)

6.1 หยุดการทำงานของ image his-connect >> docker compose down
6.2 ตรวจสอบ IMAGE ID ด้วยคำสั่ง >> docker images
6.3 ลบ image ด้วยคำสั่ง >> docker rmi -f <IMAGE ID>

หมายเหตุ

1. script ใน file docker-compose.yml

services:
  api:
    image: superpck/his-connect:linux-latest
    container_name: his-connect-api
    environment:
      - TZ=Asia/Bangkok
    ports:
      - "3004:3004"
    volumes:
      - ./config:/usr/src/his_connect/config:ro
      - ./sent_result.txt:/usr/src/his_connect/sent_result.txt
    command: ["pm2-runtime", "start", "app/app.js", "-i", "2", "--name", "his-connect-api"]
    pull_policy: always
    restart: always
    healthcheck:
      test: ["CMD", "curl", "-f", "http://localhost:3004"]
      interval: 30s
      timeout: 10s
      retries: 5

2. การเปลี่ยนแปลงแต่ละ version: CHANGELOG

ติดตั้งด้วย Node.js
  1. ติดตั้งโปรแกรมที่จำเป็นในการใช้งาน
    • เลือกติดตั้ง Node.js version 24 ขึ้นไป
      • วิธีติดตั้งบน Windows OS หรือ MacOS
      • วิธีติดตั้งบน CentOS Linux
      • วิธีติดตั้งบน Ubuntu Linux
      • ติดตั้ง package ที่จำเป็นของ Node.js >> npm install -g pm2 nodemon typescript ts-node
    • ติดตั้งโปรแกรมสำหรับ download และ update source code จาก github
  2. สมัครเพื่อขอใช้งานโปรแกรมดังนี้
    • PHER+/ISOnline V.3 (ลงทะเบียนผู้ใช้งานใหม่)
    • ระบบ nRefer (Sign up new user)
    • Github
  3. ไม่ต้องติดตั้งฐานข้อมูล isdb เหมือน version ที่ผ่านมา เนื่องจากเป็นการบันทึกไปยังฐานข้อมูลส่วนกลาง
  4. ติดตั้ง API โดย
    • สร้าง folder เพื่อติดตั้ง (เช่น >> mkdir d:\api)
    • >> cd d:\api
    • Clone source code จาก Github ด้วยคำสั่ง >> git clone https://github.com/superpck/his-connect his_connect
    • >> cd his_connect
    • ใช้คำสั่งติดตั้ง package >> npm install
  5. สร้างและแก้ไข config file (เป็น file ที่ไม่มี extension)
    • Windows
      • copy config.example config
      • ใช้ notepad หรือ editor โปรแกรมใดก็ได้เปิด file config เพื่อแก้ไข
    • Linux
      • cp config.example config
      • vi config
    • ให้ข้ามการ config ส่วน [ISDB] เนื่องจากเป็นการบันทึกข้อมูลเข้าสู่ส่วนกลางโดยตรง
    • หากต้องการใช้ protocol https ให้ระบุ SSL_ENABLE=1
    • สามารถเปลี่ยน key และ cert ให้เป็นของหน่วยงานได้โดย copy file ไปวางใน folder public/ssl
  6. run API โดยใช้โปรแกรม pm2
    • กรณี Windows ให้ติดตั้ง auto start ด้วยคำสั่ง
      • >> npm install pm2-windows-startup -g
      • >> pm2-startup install
    • กรณี Linux ให้ใช้คำสั่ง >> pm2 startup
    • start การใช้งาน API ด้วยคำสั่ง >> pm2 start app/app.js -i 2 --name "his-connect"
    • บันทึกค่าที่ใช้งานในปัจจุบัน >> pm2 save
    • ทดสอบการเชื่อมต่อฐานข้อมูล HIS ที่ http://ip:port/his/alive หรือ https://ip:port/his/alive เช่น http://192.168.0.250:3004/his/alive
  7. การ config ใช้งานโปรแกรม PHER+ และ nRefer (กรณีต้องการ)
    • nRefer
      • ใช้ url http://refer.moph.go.th กรณีเลือก SSL_ENABLE=0
      • หรือใช้ url https://nrefer.moph.go.th กรณีเลือก SSL_ENABLE=1
      • Login เข้าสู่ระบบ
      • เข้าไปที่เมนู 'Tools' -> 'Config ระบบ'
      • กำหนดค่า HIS API http://ip:port หรือ https://ip:port ที่ติดตั้ง API ไว้
      • กำหนดค่า HIS Request Key ตามที่กำหนดใน config file บรรทัด REQUEST_KEY=..
      • ทดสอบการเชื่อมต่อโดยเข้าไปที่เมนู 'ทะเบียนจาก HIS รพ.' => 'ทะเบียนส่ง Refer' หากถูกต้องจะสามารถค้นหาข้อมูลการส่ง Refer จาก HIS รพ. ได้
    • ISOnline
      • ใช้ url https://connect.moph.go.th/pher-plus กรณีเลือก SSL_ENABLE=1
      • กำหนดค่าเชื่อมต่อเป็น http://ip:port หรือ https://ip:port ที่ติดตั้ง API ไว้
      • ทำการ config API ในระบบ PHER Plus โดยกำหนดค่าเชื่อมต่อเป็น http://ip:port หรือ https://ip:port ตามที่ติดตั้ง API ไว้
  8. การ update API/Source code
    • เข้าไปที่ folder ที่ติดตั้ง API ไว้
    • ใช้คำสั่ง >> git pull
    • restart API ด้วยคำสั่ง >> pm2 restart his-connect
  9. กรณี API ไม่ทำงาน ให้ตรวจสอบดังนี้
    • ตรวจสอบโดยใช้คำสั่ง pm2 logs เพื่อแสดงข้อผิดพลาด
    • ตรวจสอบ Firewall และ AntiVirus ของเครื่องที่ติดตั้ง API ว่ามีการ block port หรือไม่
      • FirewallD on Linux
      • IPTables on Linux
    • ตรวจสอบ config ของ Router หรือ Switch ว่าได้ allow port หรือยัง
  10. คำสั่ง pm2
    • start service: pm2 start 'folder/file' [-i n] [--name "pm2Name"]
    • restart service: pm2 restart [pm2Name]
    • stop service: pm2 delete [pm2Name]
    • save state for next reboot: pm2 save
    • ตรวจสอบสถานะ: pm2 status
    • ตรวจสอบ logs การทำงาน: pm2 logs
    • monitor pm2: pm2 monit
    • stop pm2: pm2 kill

ข้อควรระวังด้านความปลอดภัย

  • user/password ที่เข้าถึงฐานข้อมูล ควรให้สิทธิ์ select อย่างเดียว
  • ควรติดตั้ง API บน IP ภายในเครือข่ายเท่านั้น (Private IP)
  • ไม่ควรติดตั้งระบบที่สามารถเข้าใช้งานจากนอกหน่วยงานได้ เช่น public ip หรือ reverse proxy
  • ไม่ควรติดตั้ง API บนเครื่องที่มีผู้ใช้งานเข้าถึงได้ง่าย เพื่อป้องกันอ่าน file config
  • เพื่อความปลอดภัยในการเข้าถึงฐานข้อมูลส่วนกลาง ควรมีการเปลี่ยนรหัสสำหรับการส่งข้อมูลส่วนกลาง (API Secret Key) ทุก 3-6 เดือน
  • ควรยกเลิกการใช้งาน username ที่มีการย้ายหน่วยงาน หรือ ที่ไม่ใช้งานแล้ว

Private IP คืออะไร

Private IP คือหมายเลข IP ที่ใช้ภายในเครือข่ายของหน่วยงานเท่านั้น ไม่สามารถเข้าถึงจากอินเทอร์เน็ตโดยตรง ผู้ติดตั้งควรใช้ IP ในช่วงต่อไปนี้ (ตามมาตรฐาน RFC 1918) สำหรับเครื่องที่ติดตั้ง API

Class ช่วง IP Subnet mask CIDR ตัวอย่าง
A 10.0.0.0 – 10.255.255.255 255.0.0.0 10.0.0.0/8 10.10.100.25
B 172.16.0.0 – 172.31.255.255 255.240.0.0 172.16.0.0/12 172.16.1.10
C 192.168.0.0 – 192.168.255.255 255.255.0.0 192.168.0.0/16 192.168.0.250

IP นอกช่วงข้างต้นถือเป็น Public IP ซึ่งไม่ควรใช้ติดตั้ง API
