ติดตั้งด้วย Node.js

อ่าน คู่มือการติดตั้ง API สำหรับขั้นตอนและการตั้งค่า

ข้อควรระวังด้านความปลอดภัย

  • บัญชีฐานข้อมูลควรมีสิทธิ์อ่านข้อมูลเท่าที่จำเป็น
  • ควรติดตั้ง API ในเครือข่ายภายใน และไม่เปิดเผยต่ออินเทอร์เน็ตสาธารณะ
  • ควรเปลี่ยน API Secret Key เป็นระยะ และยกเลิกบัญชีที่ไม่ใช้งาน
